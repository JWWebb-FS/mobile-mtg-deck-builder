# MTG Deck Vault - Native Client

A React Native mobile application for managing Magic: The Gathering decks.

## Tech Stack

- **Framework:** React Native (Expo)
- **API:** Custom MERN Backend
- **State Management:** React Hooks
- **Navigation:** React Navigation Stack

## CRUD Features

- **GET:** View all decks in the Vault.
- **POST:** Add new decks with name and color identity.
- **PUT:** Update existing deck details.
- **DELETE:** Remove decks from the database.
